## 双臂支持

双臂配置对策略来说是**透明的**，因为：

1. **状态向量**：两个臂的关节角度拼接成一个 `observation.state`
2. **动作向量**：两个臂的动作拼接成一个 `action`

例如双臂 Piper（每臂 7 自由度）：
```python
observation.state = [arm1_joint1...arm1_joint7, arm2_joint1...arm2_joint7]  # 14维
action = [arm1_action1...arm1_action7, arm2_action1...arm2_action7]         # 14维
```

策略只看到维度大小，不关心是单臂还是双臂。

## 你的配置建议（双臂 + 多相机）

```python
# 推荐数据格式
{
    "observation.images.front": (480, 640, 3),    # 前置相机
    "observation.images.left_wrist": (480, 640, 3),  # 左臂腕部

    "observation.state": (14,),   # 双臂状态 (7+7)

```

# 3. 策略特点：

### 1. 通用VLA与基础大模型 (Vision-Language-Action Models)
这一类模型利用大型语言模型（LLM）或强大的多模态Transformer作为基础，能处理视觉+语言输入，是最前沿的具身智能方向。

*   **pi0 (π₀ / Structure from Motion)**
    *   **特点**: **物理智能（Physical Intelligence）的开山之作。** 基于**Flow-Matching（流匹配）技术作为主策略（类似Diffusion但更加连续和平滑）。它通常是一个能在各种机器人上执行多种任务的通用预训练模型架构。特点是动作生成的质量很高，并且能在复杂多模态输入下保持一定的泛化能力。
    *   **技术栈**: VLA, Flow Matching, Continuous Action.

*   **pi05 (π₀.₅ / Pi Zero-Point-Five)**
    *   **特点**: **π₀的升级版，专为开放世界（Open-World）环境设计。** 特点是超强的泛化能力。相比π₀，它使用了混合数据（Heterogeneous Data）进行联合训练，包括网络数据和跨机身（Cross-Embodiment）数据。引入了更强的语义理解能力（如对复杂指令“去整理厨房”的理解）
    *   **关键点**: **Co-training (联合训练)**, Open-World Generalization.

*   **groot (NVIDIA GR00T Integration)**
    *   **特点**: **NVIDIA的人形/通用机器人基础模型集成**。 是LeRobot对Google GR00T或NVIDIA相关Foundation Model架构的的复现/微调支持。它专门设计来理解语言并控制不同构型的机器人（尤其是人形）。支持非常强大的zero/few-shot多任务能力。

*   **wall_x (WALL-OSS / Wall-X)**
    *   **特点**: **大规模具身基础模型 (World-Action-Language-Learning)。** 一个开源的通用操作模型，特点是使用**Mixture of Experts (MoE, 专家混合及)** 结构来模拟动作，具有极大规模的数据训练背景（4B参数级别），分为理解世界 dynamics（Perception/Reasoning）和产生Action的阶段。它是比较重的模型，强调对长周期任务的理解。

*   **xvla (Cross-Embodiment VLA, X-VLA)**
    *   **特点**: **专注于“跨具身（Cross-Claimer）泛化”的VLA模型。** 其核心技术是使用 **Soft Prompts（软提示词）**——它不需要为您每一个新机器人从头训练整个大模型，而是训练一个轻量级的“Embodiment Prompt”（适配器）使基础大模型适应该身体结构。参数量（训练量）极小，极其适合把一个大脑迁移用在很多不同型号的机械臂上。

*   **smolvla**
    *   **特点**: **“Smol”（Small）版的VLA。** LeRobot团队发布的更轻量级、运算效率更高视觉语言动作模型（一般基于轻量级的SmolLM或类似架构）。特点是在保持了一定的（视觉+语言->动作）推理能力的同时，大幅优化了推理速度和显存占用，更适合在端侧或中小显存GPU上部署。

### 2. 经典/SOTA 模仿学习与生成策略 (Imitation Learning & Generative)
这些是目前做Robot Learning最主流、经常用于单一任务或多任务微调的高效策略。

*   **act (Action Chunking with Transformers)**
    *   **特点**: **动作分块（Chunking）的代表作。** 
        *   这不仅预测下一步动作，而是预测未来一整块的时间片（chunk，例如1秒内的动作序列）。
        *   使用 CVAE（条件变分自编码器）来解决数据的多模态分布问题（即相同的观察有多种可能合理动作）。
        *   **优势**: 大幅减少了机器人累积误差，动作更平滑，且对不可预知的抖动更鲁棒。当前入门首先。

*   **diffusion (Diffusion Policy)**
    *   **特点**: **利用扩散模型生成动作。**
        *   将机器人动作规划看作“去噪”过程（从随机噪音一点点变成合理动作轨迹）。
        *   **极强的多模态建模能力**（例如在某个路口既可以左转也可以右转，ACT可能算出平均值导致撞墙，而Diffusion能准确生成其中**一种**可能的路径）。
        *   训练比较稳定，泛化到新场景时比经典的BC（行为克隆）强很多。但推理速度一般比ACT慢。

*   **vqbet (Vector-Quantized Behavior Transformer)**
    *   **特点**: **矢量量化的离散动作模型。**
        *   不直接预测连续动作数值，而是将动作Token 化（离散化），分成一个个离散的码本（Codebook, VQ）。
        *   使用 GPT或类BERT 的方式来预测下一个行为Token。
        *   **优势**: 对包含混合性质能的任务（比如有时要很慢有时要很快、不同的抓取方式）模拟效果很好，避免了回归问题中的平均效应。

### 3. 先进RL与优化策略
这些通常不仅仅是单纯的策略网络，而是配合强化学习机制、推理时间优化或奖励机制的方法。

*   **rtc (Real-Time Chunking)**
    *   **这其实是一种 *执行/推理策略* (Wrapper) 而非单纯的网络结构。**
    *   **特点**: 专门解决了ACT、Pi0这通过Chunk运行的策略带来的延迟问题。当机器人在执行第 $K$ 帧动作时，RTC就在“背地里”算 $K+1$ 到 $K+N$ 帧如果发生该怎么做（异步推理）。
    *   **作用**: 当网络（尤其是大VLA如Pi0）算一遍需要2秒钟，而动作只需要0.1秒时，RTC能利用时间差，加上拼接技术，保证所有生成动作无缝衔接，**消除“停那一秒思考”的体感卡顿**。

*   **sarm (Stage-Aware Reward Modeling)**
    *   **特点**：**即 SARM-R 或相关的奖励加权/训练策略**。基于对长序列任务的阶段（Stage）分析来给不同数据打分或给策略加权。可以理解为这包含了一个Reward Model（奖励模型）。主要用来区分 expert (高质量) 和 amateurish (低水平) 的数据路径。在LeRobot中通常指`Stage-Aware Reward Modeling`策略进行微调或模仿，能显著提高对长视距操纵任务（Long-horizon Manipulation）的成功率。

*   **tdmpc (Temporal Difference MPC)**
    *   **特点**: **基于模型的强化学习策略（Model-Based RL）。**
        *   在**潜在空间（Latent Space）**中进行MPC（模型预测控制）规划。它不像普通RL试图记住所有状态到动作对于关系，亦不像普通BC单纯照搬； TDMPC尝试通过理解和预测环境“可能会发生什么”来规划一步步动作。通常极其采样高效（Sample Efficient），能用很少的数据学会复杂的控制任务。

*   **sac (Soft Actor-Critic)**
    *   **特点**: **经典的基网络Reinforcement Learnning算法。** 
        *   最大熵（Maximum Entropy）强化学习。 极其标准稳健的 无模型（Model-Free）连续动作深度学习基线。
        *   在LeRobot支持库中，通常作为对照组或者用于那些定义完善的Sim环境刷分。注重探索性与利用性的平衡。

### 总结建议：
*   **如果不清楚选什么**：首选 **ACT**（简单、高效、足够解决基础操作），想上限更高尝试 **Diffusion**。
*   **需要强感知理解（“帮我吧那个红苹果拿过来...”）**: 选 **pi05**、**xvla** 或 **smolvla**（如果显存小）。
*   **动作大、反应慢了很顿?**：检查策略配置是否开启了 **RTC** 推理模式。
*   **做复杂长任务老失败？**: **sarm** (加入阶段意识奖励, 对复杂的顺序性任务很有效), 或者 **wall_x** (大模型暴力美学)。
